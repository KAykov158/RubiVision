# Phase gates and evidence

0 Audit: repository map, scripts, existing behavior, dependency choices, initial failing checks, ADRs. 1 Foundation: responsive navigation and auth-aware app shell. 2 Timer + scrambles: state machine, monotonic clock, correct penalty boundaries, immutable scramble snapshot. 2A Supabase: auth, migrations, RLS, typed repositories, cloud save states, cross-device and cross-user tests. 3 Solves: CRUD, pagination, filters, penalty edits, idempotency and delete policy. 4 Statistics: golden vectors, rolling averages, full-data semantics. 5 Camera: permission, file import, recording, offset, consent. 6 Vision: deterministic features, timestamps, cancellation, quality flags. 7 Dataset/ML: consented labels, leakage-safe split, baseline and trained comparison on untouched test. 8 Inference: manifest validation, confidence, timeline, replay and correction. 9 Import/export/settings: versioned schema, transactional import and user ownership. 10 Final QA: CI, accessibility, security, documentation, demo. 11+ Optional scanner/smart cube/exact turn research only after earlier gates.

Every gate requires: typecheck; lint; unit tests; integration/e2e appropriate to scope; build; recorded command output; manual acceptance steps; no unresolved critical data-loss/security defects. A feature is NOT done if tests are skipped, unexecuted or depend on invented fixtures. Record actual evidence in docs/verification-log.md.
