# RubiVision AI / Statistics — Task 03: WCA-style trimmed averages and golden vectors

## Goal and exact implementation requirements
Implement a documented WCA-style trimmed average for N=5,12,50,100 using exactly N consecutive solves. Trim count per side = ceil(0.05*N), so 1 for ao5 and ao12, 3 for ao50, 5 for ao100. Sort window values for trimming while preserving chronological window membership. Treat DNF as +infinity solely for ranking; a trimmed DNF can be removed among worst values. If any DNF remains after worst-side trimming, average is DNF. Trim the required number of best and worst entries even with ties; calculate arithmetic mean of remaining finite effective times. Do not drop DNF solves from window or substitute 0. Preserve raw millisecond precision; specify presentation rounding separately and verify against current official WCA regulations before claiming formal compliance. Return status, N, window solve IDs, trim count, retained count, valueMs when valid, and DNF details.
Golden fixtures: ao5 [10000,11000,12000,13000,14000] -> 12000; ao5 [10000,11000,12000,13000,DNF] -> 12000; ao5 [10000,11000,12000,DNF,DNF] -> DNF; ao12 with 12 consecutive finite values; ao50 and ao100 trim counts; +2 applied before ordering; exactly N-1 -> insufficient. Tests must be independent hand-calculated expected outputs, not generated by the implementation itself.
